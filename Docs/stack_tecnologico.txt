DOCUMENTACIÓN TÉCNICA - CASINO DAW 
1. ARQUITECTURA GENERAL
El proyecto emplea una arquitectura modular donde el Dashboard centraliza la experiencia del usuario. Los juegos funcionan como nodos independientes integrados mediante una API REST (PHP) que garantiza la persistencia de datos en una base de datos MySQL y la sincronización del saldo en tiempo real.

2. FRONTEND Y COMPONENTES GLOBALES
Tecnologías: HTML5, CSS3, Bootstrap 5.3 y JavaScript ES6 funcional.

Gestión Visual: Uso de ConfettiManager.js para disparar celebraciones basadas en la librería Canvas Confetti al detectar hitos o premios.

Gestión de Audio: AudioManager.js centraliza los efectos de sonido (giros, clics, victorias y pérdidas) en todos los módulos.

Navegación: Sistema de componentes dinámicos para navbar.html y footer.html.

3. SISTEMAS TRANSVERSALES
Billetera Unificada: El saldo se gestiona mediante peticiones POST a api.php?action=game_result, actualizando el estado global sin necesidad de recargar la página.

Sistema de Logros: Implementación de medallas dinámicas (Primer Paso, Ganador Novel, Superviviente, Poker Face, Estratega Texas) que se desbloquean al cumplir condiciones específicas en los juegos.

4. MÓDULOS DE JUEGO (DETALLE TECNOLÓGICO)
A. RULETA EUROPEA
Ruta: /games/Ruleta

Lógica: Basada en el orden oficial del cilindro europeo (37 números).

Innovación: Cálculo de rotación negativa precisa para alinear el número ganador con el indicador visual y sistema de fichas acumulativas que suma el valor en la misma celda para evitar saturación del DOM.

B. MÁQUINA TRAGAPERRAS (SUPER SLOTS)
Ruta: /games/Tragaperras

Motor de Azar: Sistema de probabilidades pesadas (Cereza 40% a Diamante 5%) que garantiza la sostenibilidad del casino.

Frontend: Animaciones CSS para el giro y parada secuencial de carretes (efecto cascada) con un intervalo de 1.2 segundos entre cada uno para aumentar la tensión del usuario.

C. CRASH (COHETE)
Ruta: /games/Crash

Gráficos: HTML5 Canvas para renderizar la curva exponencial del multiplicador en tiempo real.

Lógica: Algoritmo de explosión aleatorio limitado a un máximo de 40x con funcionalidad de Auto-Retiro configurable por el usuario.

D. CARRERA DE CABALLOS
Ruta: /games/Carrera

Algoritmo: Simulación de velocidad asíncrona ponderada por las cuotas de cada corredor (Relámpago, Fantasma, etc.) y probabilidad de "Turbo" aleatorio.

E. BLACKJACK (MICROSERVICIO)
Ruta: /games/Blackjack

Backend: Java con Spring Boot actuando como motor de lógica de cartas independiente (Microservicio en puerto 8080).

Comunicación: Fetch API para consumir el estado de la mano, puntos y validación de reglas de la banca.

F. POKER CLÁSICO Y TEXAS HOLD'EM
Ruta: /games/Poker

Estado: Funcionales y habilitados.

Lógica Texas: Sistema de 2 cartas propias y 5 comunitarias con evaluador de manos de alta jerarquía (desde Carta Alta hasta Escalera Real).

Lógica Clásico: Modalidad 5-Card Draw con sistema de descarte y mantenimiento de cartas.

5. AUTOMATIZACIÓN Y CI

Scripts de Mantenimiento: Carpeta /CI con herramientas de respaldo.

Persistencia Crítica: El script backup_db.sh garantiza la integridad de las tablas de usuarios y logros ante fallos en el despliegue.
